## Pro Content Tips

### 1. Structure Your Article

Start with:
- Hook (why should they read this?)
- Context (what's the situation?)
- Main content (organized in clear sections)
- Actionable takeaways (what should readers do?)
- Conclusion (summarize key points)

### 2. Image Placement Best Practices

**Where to place images:**
- After the introduction (sets visual context)
- Between major sections (breaks up text)
- To illustrate specific points (show, don't just tell)
- Before conclusions (visual summary)

**Image tips:**
- Use descriptive filenames: `teaching-strategy-diagram.webp` not `img001.webp`
- Keep images under 500KB for fast loading
- Use .webp format for best quality/size ratio
- Always include alt text for accessibility

### 3. Make It Scannable

Readers often scan before reading. Help them by:
- Using clear headings and subheadings
- Breaking text into short paragraphs (3-4 lines max)
- Adding bullet points for lists
- Using bold for key terms
- Including images to break up text
